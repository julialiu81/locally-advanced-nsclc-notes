# 局部晚期非小細胞肺癌・試驗互動筆記

整理非小細胞肺癌（NSCLC）術前、圍手術期與不可切除第 III 期治療的關鍵臨床試驗，以單一網頁呈現 31 項試驗的設計、結果與解讀，並可並排比較。資料以正式發表論文為主，並納入 WCLC 2026（首爾）現場報告的最新結果。

## 線上閱讀
開啟 `index.html`，或直接瀏覽 GitHub Pages：<https://julialiu81.github.io/locally-advanced-nsclc-notes/>

## 內容
- 依可切除性分三層：可切除（術前／圍手術期免疫、術前標靶、術後標靶、術後免疫與升降階）、邊界可切除、不可切除第 III 期（化放療後鞏固、化放療開始即隨機、誘導後化放療）。
- 每項試驗分四個分頁：設定與方法（含治療流程圖）、研究結果（含風險比圖）、解讀與限制、資料來源。
- 「研究比較」可同時並排最多六項試驗；「主題閱讀」以短文與表格整理方法學、分母與限制。
- 參考文獻逐筆標示來源類型（同儕審查論文、會議摘要、會議簡報、新聞稿、試驗登錄、法規文件）。會議報告的數字以簡報為據，待正式發表後更新。
